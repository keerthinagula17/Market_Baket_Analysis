# Power BI Dashboard Guide — Market Basket Analysis

## Important
A `.pbix` file is **not included**. Power BI Desktop creates PBIX files locally. This guide uses the CSV outputs generated by the notebook.

## Data to Import
Import:
- `outputs/frequent_itemsets.csv`
- `outputs/association_rules.csv`

For the KPI/product/country/time visuals, import the cleaned transaction dataset generated or retained during notebook execution. The notebook also creates an in-memory `clean_df`; if you want a persistent Power BI fact table, export that dataframe to CSV from the notebook.

## Dashboard Layout
### 1. KPI Cards
- **Total Revenue:** SUM(Revenue)
- **Total Transactions:** DISTINCTCOUNT(InvoiceNo)
- **Total Products:** DISTINCTCOUNT(StockCode)
- **Average Basket Size:** AVERAGE(BasketSize)

### 2. Sales Overview
- Line chart: `InvoiceMonth` vs Revenue
- Clustered bar chart: `Country` vs Revenue
- Bar chart: Top 10 products by Revenue

### 3. Basket Analysis
- Histogram/column chart: Basket Size distribution
- Table: InvoiceNo, BasketSize, Revenue

### 4. Frequent Itemsets
Use `frequent_itemsets.csv`.
- Table: Itemset, Support, Item Count
- Bar chart: Top itemsets by Support

### 5. Association Rules
Use `association_rules.csv`.
- Table: Antecedents, Consequents, Support, Confidence, Lift
- Scatter chart: Confidence vs Support, bubble size = Lift
- Bar chart: Top rules by Lift

## Recommended Filters
- Country
- Invoice Month
- Minimum Support
- Minimum Confidence
- Minimum Lift

## Suggested DAX
```DAX
Total Revenue = SUM('Clean Transactions'[Revenue])

Total Transactions = DISTINCTCOUNT('Clean Transactions'[InvoiceNo])

Total Products = DISTINCTCOUNT('Clean Transactions'[StockCode])

Average Basket Size = AVERAGE('Basket Summary'[BasketSize])
```

## Rule Interpretation
- **Support:** prevalence of the full itemset.
- **Confidence:** conditional likelihood of the consequent given the antecedent.
- **Lift > 1:** the two sides occur together more often than expected under independence.

## Professional Design
Use a clean white canvas, consistent typography, KPI cards at the top, sales trends in the middle, and market-basket visuals on the lower section. Add a short methodology text box explaining that cancelled/invalid transactions were excluded from the sales basket analysis.

## Export
After building the dashboard, save it as `Market_Basket_Analysis.pbix`. Do not commit sensitive credentials or local file paths.
